# D2R 리이매진드 온라인

D2R Reimagined Online은 **D2R Reimagined**를 기반으로 한 비공식 D2RLAN 호환 빌드입니다.  
싱글 플레이와 D2RLAN 호환 환경을 통한 TCP/IP 멀티플레이를 위해 제작되었습니다.

이 프로젝트는 공식 D2R Reimagined 모드와는 별도로 관리됩니다.

공식 D2R Reimagined 저장소:  
https://github.com/D2R-Reimagined/d2r-reimagined-mod

## 상태

이 빌드는 D2R Reimagined의 **공식 버전이 아닙니다**.

이 빌드에서 발생하는 버그, 충돌, 누락된 기능, 멀티플레이 문제 또는 호환성 문제는 공식 D2R Reimagined 프로젝트의 문제가 아니라, 이 D2RLAN 호환 버전의 문제로 봐주시기 바랍니다.

현재 **3.x 버전**이 이 빌드의 권장 안정 버전입니다.

## 목적

이 버전은 D2RLAN이 최신 공식 D2R 클라이언트보다 오래된 D2R 클라이언트 환경을 사용하기 때문에 제작되었습니다.

이 빌드는 다음 환경에서 D2R Reimagined를 플레이하려는 유저를 위해 설계되었습니다.

- 싱글 플레이
- TCP/IP 멀티플레이
- D2RLAN 호환 환경

이 빌드는 오래된 클라이언트 환경을 대상으로 하기 때문에, 최신 공식 오프라인 버전에 포함된 일부 기능은 사용할 수 없거나 다르게 동작할 수 있습니다.

## 지원 기능

- D2RLAN을 통한 TCP/IP 멀티플레이
- D2R Reimagined의 대부분의 게임플레이 시스템
- Warlock을 제외한 대부분의 Reimagined 클래스
- 공식 D2R 클라이언트 업데이트로 인해 빌드가 깨질 위험 감소
- 최신 클라이언트에서는 쉽게 사용할 수 없는 일부 하드코딩 기반 모딩 가능성
- 다수의 공유 보관함 탭

## 알려진 제한 사항

### 워록

워록 클래스는 D2RLAN에서 사용할 수 없습니다.  
단, 추후 D2RLAN 지원 여부에 따라 추가될 수 있습니다.

### 모자이크

현재 모자이크 어쌔신의 차지 유지 기능은 지원되지 않습니다.

### 악군의 중첩 창고

현재 스택형 보관함 시스템은 사용할 수 없습니다.

### 버전 차이

공식 Reimagined 버전의 대부분의 업데이트가 포함되어 있습니다.  
다만 일부 기능은 제한되었거나 수정되어 있습니다. 자세한 내용은 문서를 참고해 주세요.

## 멀티플레이 참고 사항

TCP/IP 멀티플레이에서는 모든 플레이어가 다음 항목을 동일하게 맞춰야 합니다.

- 동일한 모드 버전
- 동일한 D2RLAN 호환 클라이언트 환경
- 일치하는 모드 파일

파일이 서로 다를 경우 충돌, 누락된 그래픽, 깨진 스킬 또는 기타 예기치 못한 문제가 발생할 수 있습니다.

감사합니다, Ben.
